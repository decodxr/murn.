# murn. v0.14.0 — core overhaul

v0.14 focuses on making murn. more consistent as a system rather than treating the underlying LLM as the whole assistant.

## Adaptive intelligence

Every request is classified locally without an extra model call:

- `coding`: low-temperature engineering/debugging behavior.
- `language`: rewriting, translation and linguistic work while preserving voice.
- `factual`: conservative sampling for factual questions.
- `general`: normal murn. personality with reliability rules.

Relevant specialist prompts are loaded only for the current request. This keeps ordinary chat small and fast.

The debug console emits a `profile` event with the selected profile and sampling values.

## Action reliability

Tool routing now considers recent conversation history. Follow-ups such as:

```text
create an image of yourself
no, I mean the face
create it
```

stay in the image-generation flow. Browser follow-ups work similarly.

For explicit actions, the agent tracks one concrete required tool/action. If the model attempts to answer around the action instead of calling the available tool, the first text is discarded and one internal tool-use retry is issued. This prevents responses such as “I cannot create images” while `generate_image` is available.

## Coding workspace

Read-only local workspace tools:

```text
workspace_roots
workspace_list
workspace_read
workspace_search
workspace_git_status
workspace_git_diff
```

Default roots:

```env
MURN_WORKSPACE_ENABLED=true
MURN_WORKSPACE_ROOTS=~/Projects;~/Orbital
MURN_WORKSPACE_MAX_FILE_CHARS=40000
```

Only add directories that you are comfortable allowing the agent to inspect. Paths are resolved against the allowlist; external paths and symlink escapes are rejected/skipped. Binary/model/media files and common build/vendor directories are excluded.

There is intentionally no arbitrary shell execution or file mutation in this version.

## Deterministic calculator

`calculate` evaluates a restricted arithmetic AST locally so straightforward calculations are not left to probabilistic token prediction. It supports arithmetic and common functions such as `sqrt`, `sin`, `cos`, `log`, `round`, `min` and `max` without `eval` or arbitrary Python execution.

## Desktop mini voice mode

The desktop topbar contains `MINI` and `Ctrl+Shift+M` enters mini mode.

Native Tauri commands resize the actual KDE window to approximately `410 × 560`, reduce the minimum size and enable always-on-top. The mini UI is served at `/mini` and contains:

- animated murn. orb;
- waveform reacting to microphone input;
- waveform reacting to Piper output while murn. speaks;
- hold-to-talk;
- automatic VAD/listening mode;
- native always-on-top toggle;
- expand button back to the full application;
- current conversation session continuity.

The mini UI uses the normal `/v1/voice/chat` pipeline, so its voice turns are real persisted murn. conversation turns. Expanding returns to the same conversation.

## Backend consistency fixes

- Debug router is explicitly registered.
- Identity prompt is passed explicitly into the Agent.
- configured Ollama sampling values reach the provider.
- direct `/v1/images/generate` also unloads the resident LLM before ComfyUI to reduce VRAM collisions.
- `/health` exposes workspace/adaptive-intelligence state.
- `/mini` receives the same no-cache behavior as desktop/mobile UIs.
- voice requests can identify their source for global debug traces.

## Install / upgrade

Python changes:

```fish
cd ~/Projects/murn
git pull
source .venv/bin/activate.fish
python -m pip install -e '.[voice]'
.venv/bin/pytest -q
```

The Tauri shell changed, so rebuild/reinstall it:

```fish
bash scripts/install_desktop_app.sh
```

Then launch:

```fish
murn-desktop
```

Verify:

```fish
curl -s http://127.0.0.1:7332/health | jq '{version, adaptive_intelligence, workspace, workspace_roots, debug}'
```

Expected version: `0.14.0`.
